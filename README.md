# Inline Evidence Insights

Proof of concept for inline evidence insights inside the Heidi note: hover popovers reveal supporting evidence pulled from the patient record, and a drug-interactions check runs against the Heidi evidence layer so clinicians can spot conflicts without leaving the note.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000.

## Deploy

This repo is auto-deployed to Railway on every push to `main`.

Live URL: https://inline-evidence-insights-production.up.railway.app
